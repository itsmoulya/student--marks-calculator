# Student Marks Calculator

## About
This is my first Python project. It calculates the total marks and percentage of a student across five subjects.

## Features
- Accepts the student's name
- Takes marks for five subjects
- Calculates total marks
- Calculates percentage
- Displays the student's result

- Python
